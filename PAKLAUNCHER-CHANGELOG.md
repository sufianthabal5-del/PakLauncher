# PakLauncher rebrand and UI pass

- Rebranded app display name to PakLauncher.
- Set Android application ID to `com.pak.launcher`.
- Kept internal namespace and engine packages stable to avoid breaking existing runtime code.
- Added original PakLauncher neon-green emblem and brand artwork.
- Applied consistent black / neon-green / white visual tokens to the existing launcher UI resources.
- Added a PakLauncher GitHub Actions APK workflow.
- Preserved existing Minecraft runtime, Java runtime integration, version/mod-loader systems and licensing notices.

This is a source rebrand and UI styling pass, not a claim that all existing screens have been independently redesigned or that the APK has passed device QA. Build and test the resulting APK before public distribution.
